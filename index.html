制作可直接分享的日程工具

这页只需要发布者设置一次。生成分享版后，朋友打开只需注册或登录，不会看到任何技术配置。

普通使用者不需要 Supabase，也不需要运行代码。下面三步只由你完成一次。

1创建免费云空间

点击按钮，在 Supabase 注册并新建一个项目。项目名称可以随意填写。

打开 Supabase

2准备日程数据表

填写你已验证的登录邮箱。这个邮箱会加入管理员白名单，可以只读查看所有成员的日程。

在 Supabase 左侧打开 SQL Editor，点击 New query，粘贴代码并点击 Run。旧版本升级时也重新运行一次，不会删除已有日程。

需要时查看代码

3生成给朋友的版本

在 Supabase 的 Project Settings → API 页面复制下面两项。不要填写 service_role。

生成的文件名是“日程清单-分享版.html”。把这一个文件发给朋友即可；朋友无需重复以上步骤。
